# WipyBot Context

WipyBot is a Discord bot scaffold for guild tooling. The previous Mythic+ matchmaking feature has been removed so the project can be repurposed for raid signups.

## Current Scope

- Discord bot startup and slash command syncing.
- Per-guild SQLite settings.
- Optional FastAPI admin dashboard protected by Basic Auth.
- Runtime JSONL event logging.
- Voice move admin utility (`/move` and `/setup_move`).

## Planned Direction

- Raid signup creation and attendance/spec selection.
- Dynamic Discord signup status messages.
- Future integration with the guild logs web project.
